# Blanky 법적 고지

데스크탑 펫 앱 **Blanky(블랭키)** 의 공개 문서입니다.

- [개인정보 처리방침](https://blankymunn3.github.io/blanky-legal/)

앱 소스는 별도 비공개 저장소에서 관리하며, 이 저장소는 스토어(Microsoft Store · Mac App Store)가
요구하는 공개 문서를 게시하기 위한 용도입니다.

정본은 앱 저장소의 `etc/privacy_policy.md` 이며, 이 저장소의 `index.html` 은 그것을 렌더한 결과입니다.
