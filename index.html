1. 적용 범위

본 방침은 아래 Blanky 앱에 공통 적용되며, 플랫폼에 따라 다른 항목은 [macOS] · [Windows] 로 표시합니다.

  • [macOS] Mac App Store 판, GitHub에서 내려받는 DMG 판
  • [Windows] Microsoft Store 판, 인스톨러(exe) 판

앱은 회원가입·로그인 없이 동작하며, 이름·이메일·전화번호 등 신원 정보를 수집하지 않습니다. 다만 아래 §3에 적은 경우에 한해 제한된 정보가 외부로 전송됩니다.

3. 외부 전송

앱은 다음의 경우에 한해 외부와 통신합니다.

(가) 프로모션 코드 사용 시 — Google Firestore (미국) 이용자가 프로모션 코드를 입력하고 확인을 누르면, 코드가 개발자가 관리하는 Google Firestore로 전송되어 유효성을 확인합니다. 코드가 유효하면 사용 사실과 사용 시각이 기록됩니다. [macOS] 이때 중복 사용을 막기 위해 기기별 임의 식별자가 함께 기록됩니다. 이 식별자는 무작위로 생성된 값이며 이름·이메일 등 신원 정보와 연결되지 않습니다. [Windows] 매번 새로 생성되는 일회용 값이 기록되므로 기기를 식별하지 않습니다. 이 통신은 이용자가 코드를 입력할 때만 발생하며, 주기적·자동 전송은 없습니다.

(나) 오류 진단 정보 — Sentry (미국) · [Windows] 전용 · 기본값 꺼짐 이용자가 동의한 경우에 한해, 앱이 예기치 않게 종료될 때 오류 내용과 발생 위치(스택 추적), 실행 환경(운영체제·설치된 구성요소 목록), 앱 버전이 전송됩니다. 동의는 첫 실행 시 묻고 기본값은 꺼짐이며, 트레이 메뉴에서 언제든 끌 수 있습니다. 이름·이메일·결제 정보는 전송하지 않으며, 사용자 계정 이름과 컴퓨터 이름은 전송 전에 제거합니다. 앱 이용 기록·행동 통계는 수집하지 않습니다. [macOS] 판에는 이 기능이 없습니다.

(다) 인앱 구매 — Apple App Store / Microsoft Store 구매·구매 복원 시 각 스토어와 통신합니다. [macOS] 앱을 실행할 때 이미 구매한 항목이 있는지 자동으로 조회합니다. 결제 수단 정보는 각 스토어가 관리하며 개발자는 접근할 수 없습니다.

(라) 이용자가 링크를 누른 경우 후원 링크(ko-fi.com)를 누르면 기본 브라우저로 외부 사이트가 열립니다. 앱이 이용자 정보를 덧붙이지는 않으나, 접속 과정에서 이용자의 IP 주소 등이 해당 사이트에 전달됩니다.

(마) 이용자가 공유를 실행한 경우 [macOS] 펫 이미지를 공유하면 이용자가 고른 대상(메일·메시지·AirDrop 등)으로 이미지 파일과 텍스트가 전달됩니다. 전달 대상은 이용자가 직접 선택합니다.

위 (가)~(마) 외에 앱이 자동으로 전송하는 정보는 없습니다. 광고 SDK와 이용 행태 분석 도구는 사용하지 않습니다.

이용자는 국외 이전을 거부할 수 있습니다. 다만 (가)는 프로모션 코드를 사용하지 않으면 발생하지 않고, (나)는 동의하지 않거나 트레이 메뉴에서 끄면 발생하지 않으며, (다)는 인앱 구매를 이용하지 않으면 발생하지 않습니다.

5. 처리 위탁·제3자 제공

개발자는 이용자의 개인정보를 판매하거나 마케팅 목적으로 제3자에게 제공하지 않습니다. 위 §4의 사업자는 서비스 제공에 필요한 범위에서만 정보를 처리하는 수탁자입니다.

6. [macOS] 자동 먹이찾기 기능

이 기능을 켜면 펫이 먹이를 찾기 위해 바탕화면의 파일 이름 목록을 주기적으로 확인하고, 대상 파일을 휴지통으로 이동합니다. 또한 이용자가 펫 위로 끌어다 놓은 파일도 휴지통으로 이동합니다.

  • 파일의 내용은 읽지 않으며, 파일 이름이나 목록을 외부로 전송하지 않습니다.
  • 파일은 영구 삭제되지 않고 휴지통으로 이동하므로 복원할 수 있습니다.
  • 이 기능은 설정에서 끌 수 있으며, 끄면 바탕화면에 접근하지 않습니다.

7. 보유 기간 및 파기

기기 내 데이터는 이용자가 앱을 사용하는 동안 보관되며, 아래 경로에 저장됩니다.

  • [macOS] Mac App Store 판: 앱 샌드박스 컨테이너 내부

외부에 기록된 데이터는 프로모션 코드 사용 기록(코드·사용 시각·[macOS] 기기별 임의 식별자)뿐이며, 코드 관리 목적을 달성하면 파기합니다. 삭제를 원하시면 §10의 연락처로 요청해 주세요.
